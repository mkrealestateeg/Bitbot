# دليل تثبيت Khtb Lab بالعربي

## قبل البدء
هذه نسخة مستقلة عن مستودع Khtp الحالي. لا تستبدل ملفات المشروع القديم. الوضع الافتراضي محاكاة محلية PAPER، ولا يتم إرسال أوامر تداول للمنصة في هذه النسخة.

## التشغيل على جهازك أو سيرفر Linux

1. ثبّت Python 3.11 أو أحدث.
2. ارفع المجلد إلى مستودع GitHub جديد باسم `khtb-lab`.
3. على السيرفر استنسخ المستودع وثبّت الاعتماديات:

   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -e '.[test]'
   cp .env.example .env
   ```

4. أنشئ بوت Telegram جديدًا عبر `@BotFather`، ثم ضع التوكن في `.env`.
5. ضع رقم المستخدم الرقمي في `TELEGRAM_ALLOWED_USER_IDS`. إذا تركته فارغًا فلن يقبل البوت أوامر التحكم.
6. اترك الإعدادات التالية كما هي في البداية:

   ```dotenv
   TRADING_ENV=paper
   TRADING_MODE=MANUAL
   ENABLE_EXCHANGE_ORDERS=false
   DEMO_TRADING_ARMED=false
   LIVE_TRADING_ARMED=false
   ```

7. اختبر وشغّل:

   ```bash
   pytest -q
   python main.py
   ```

## الأوامر الأساسية

- `/start` للمساعدة
- `/status` للحالة
- `/coins` للعملات
- `/coin_add FET/USDT:USDT` لإضافة عملة
- `/scan` لتحليل السوق
- `/mode AUTO` لتفعيل المحاكاة التلقائية فقط
- `/profile SAFE` أو `/profile ADVENTURER`
- `/open SYMBOL LONG ENTRY STOP TARGET` لتسجيل صفقة ورقية يدوية
- `/closeall` ثم `/closeall confirm` لإغلاق الصفقات الورقية
- `/trades` و`/stats`

## تنبيه مهم
يدعم المشروع تنفيذ أوامر Bitget UTA في Demo وLive، لكن إرسالها معطّل افتراضيًا. تُقرّب الكمية وأسعار الحماية حسب دقة السوق؛ يُرسل أمر الدخول أولًا، وبعد تأكيد تنفيذه يرسل البوت أمر حماية TPSL منفصلًا ويتحقق من ظهوره ضمن الأوامر النشطة. قبل كل دورة مسح في Demo/Live، يطابق البوت المراكز المفتوحة وأحجامها وحمايتها مع سجل الصفقات؛ أي مركز غير معروف أو استجابة غير قابلة للتحقق توقف فتح صفقات آلية جديدة لذلك المسح، ولا تغلق المراكز تلقائيًا. إذا تعذّر تأكيد الحماية، ينبه البوت إلى أن المركز مفتوح وغير محمي. اختبر هذا المسار يدويًا في Demo وتحقق من المركز وأوامر الحماية على Bitget قبل التفكير في تفعيل Live؛ نجاح الاختبارات المحلية لا يثبت قبول المنصة للأوامر في حسابك.

ينشئ تيليجرام رسالة متابعة قابلة للتحديث مستقلة لكل صفقة ومستخدم مسموح، وتتضمن السعر وPnL تقديريًا قبل الرسوم والتمويل ومستويي SL/TP وزر إغلاق خاصًا بالصفقة. يُحدّث السعر حسب فترة المسح؛ وتُرسل تنبيهات قرب الهدف عند بلوغ 90% من المسافة إليه، وعند TP1 المحسوب عند 1R. هذه أحداث تنبيه فقط ولا تنفذ خروجًا جزئيًا أو Trailing Stop. عند الإغلاق التلقائي أو اليدوي تُحدّث رسالة الصفقة بملخص ونتيجة تقديرية. الإغلاق الفردي من تيليجرام متاح في وضع one-way فقط، ويتحقق البوت من اختفاء المركز على المنصة قبل تسجيله مغلقًا؛ أما hedge mode فيُرفض فيه زر الإغلاق الفردي لتجنب إغلاق مركز آخر على الرمز نفسه.
