# Khtb Lab V3 — UTA Final Build

This build is based on the uploaded `Khtb_Lab_V3_UNIFIED_FINAL_2.zip`.

## Included
- Bitget UTA v3 private REST adapter for DEMO and LIVE.
- UTA account assets parsing using `usdtEquity` plus USDT asset fallback.
- Demo requests automatically include `paptrading: 1`.
- Separate DEMO/LIVE credentials and independent arming gates.
- UTA futures order placement with clientOid.
- Fill confirmation by UTA order-info polling before a trade is recorded as opened.
- Preset market TP/SL attached to the opening futures order.
- UTA leverage configuration per symbol.
- Manual, DEMO AUTO and LIVE AUTO flow retained.
- Gemini is gated behind technical opportunity filtering and cooldown.
- Telegram opportunity notification, AUTO-ready notification, trade-opened notification, and execution errors.
- Telegram CLOSE ALL now routes to the UTA close-positions endpoint.
- Status shows Equity and Available USDT plus UTA/margin/position configuration.

## Safety
LIVE execution remains disabled unless both `ENABLE_EXCHANGE_ORDERS=true` and `LIVE_TRADING_ARMED=true` are explicitly enabled.
DEMO likewise requires `ENABLE_EXCHANGE_ORDERS=true` and `DEMO_TRADING_ARMED=true`.

## Important
The UTA REST order ACK only confirms that Bitget accepted the request; this build polls order status and requires a filled order with a positive fill quantity before reporting `TRADE OPENED`.
